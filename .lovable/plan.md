# תוכנית: אפליקציית שליחים

## מטרה
דף/אפליקציה נפרדת לשליחים ב-`/courier` שאפשר להוסיף למסך הבית. שליחים מקבלים התראות פוש על משלוחים חדשים, לוחצים "אני לוקח" ורואים היסטוריה + הכנסות חודשיות.

## דפים חדשים
- **`/courier/install`** — עמוד ציבורי עם הסבר + הוראות התקנה למסך הבית (iOS/Android) + כפתור הרשמה/כניסה. זה הקישור שתשלח לשליחים.
- **`/courier/login`** — הרשמה (שם, טלפון, סיסמה) + כניסה. הרשמות חדשות נכנסות במצב "ממתין לאישור".
- **`/courier/pending`** — מסך "המנהל צריך לאשר אותך" למי שעוד לא אושר.
- **`/courier/app`** — המסך הראשי לשליח מאושר: משלוחים פתוחים לחטיפה + היסטוריה + סה"כ הכנסות החודש. מבקש הרשאת התראות אוטומטית.
- **`/admin/couriers`** — למנהל: אישור/דחייה/השבתה של שליחים, וצפייה בביצועים.

## זרימה
1. שליח פותח את הקישור, נרשם, נכנס לסטטוס "ממתין".
2. אתה מאשר אותו ב-`/admin/couriers`.
3. הוא נכנס פעם אחת — הסשן של Supabase נשמר לתמיד (auto refresh), נשאר מחובר.
4. כשלקוח מתחיל תהליך משלוח (או מזמין) — פוש יוצא לכל השליחים המאושרים עם כתובת/פרטים/תשלום לשליח.
5. שליח לוחץ "אני לוקח את המשלוח" (כפתור ירוק) — המערכת מסמנת שהוא לקח (הראשון זוכה), שאר השליחים רואים "נלקח".
6. כשההזמנה נסגרת/מסופקת — נרשם לו הסכום להיסטוריה ולסיכום החודשי.

## מסך השליח
- באנר גדול לכל משלוח פתוח: כתובת, מרחק/זמן משוער, סכום לשליח, כפתור ירוק "אני לוקח את המשלוח".
- טאב "המשלוחים שלי": רשימת המשלוחים האחרונים + סטטוס.
- כרטיס למעלה: "החודש עשית X משלוחים, ₪Y".

## פרטים טכניים

**DB (מיגרציה):**
- `couriers` — user_id (auth), name, phone, status (`pending`|`approved`|`suspended`), approved_at, approved_by.
- `courier_push_subscriptions` — endpoint/keys לפוש.
- `courier_deliveries` — order_id, courier_id, status (`open`|`taken`|`completed`|`cancelled`), payout, taken_at, completed_at. יצירת שורה `open` בכל בקשת משלוח חדשה.
- RLS: שליח רואה רק את עצמו + משלוחים פתוחים/שלו. אדמין רואה הכל.

**Edge functions:**
- `courier-claim` — מבצע `UPDATE ... WHERE status='open'` אטומי כדי שרק אחד יזכה.
- `notify-couriers-new-delivery` — שולח Web Push (VAPID קיים) לכל השליחים המאושרים כשנפתח משלוח.
- טריגר על `delivery_requests` שקורא ל-`notify-couriers-new-delivery`.

**התראות:**
- Web Push עם ה-VAPID keys הקיימים בפרויקט. עובד ברקע גם כשהאפליקציה סגורה (Android מלא, iOS 16.4+ אחרי הוספה למסך הבית).
- Service worker ייעודי לקוריירים או שימוש בקיים.

**אימות:**
- Supabase email+password (טלפון כשדה בפרופיל). `persistSession: true` כבר מוגדר → מחובר לתמיד.
- role חדש `courier` ב-user_roles (נוסף רק אחרי אישור מנהל).

## נקודות שדורשות אישור לפני מימוש
1. **תשלום לשליח**: מה הסכום שנרשם לכל משלוח? האם זה שווה ל-`delivery_fee` של ההזמנה, סכום קבוע, או משתנה שאתה מגדיר לכל שליח?
2. **התראה מתי בדיוק**: (א) ברגע שלקוח מתחיל לבחור כתובת משלוח, או (ב) רק אחרי שהזמנה שולמה ואושרה? (ב' פחות רעש, יותר הגיוני)
3. **אישור טלפון**: להוסיף OTP ב-WhatsApp להרשמת שליח (כמו ללקוחות) או רק סיסמה מספיקה?
4. **מיקום השליח**: לשלוח לך מיקום GPS שלו בזמן אמת בזמן משלוח, או שזה לא נדרש כרגע?
