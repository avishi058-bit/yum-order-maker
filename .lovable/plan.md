## דף ניהול מלאי - הבקתה

### 1. גישה
- מסלול: `/inventory/<token-סודי>` - בלי התחברות, בלי סיסמה.
- token אקראי 32 תווים - אצור אותו פעם אחת ואתן לך את הלינק המלא להעתקה אחרי הבנייה.
- כל מי שאין לו את הלינק - מקבל 404.

### 2. אריזות (presets) לפי הנתונים שלך
```text
קציצה 220g       → ארגז = 37 יח׳ (8 ק"ג), יחידה, חצי קילו, קילו
לחמניה רגילה    → יחידה, חבילה (כמה? תגיד לי אחר כך)
צ׳יפס רגיל       → ארגז = 10,000g, חבילה = 2,500g, מנה = 250g, קילו, חצי קילו
צ׳יפס בטטה       → ארגז = 10,000g, חבילה = 2,500g, מנה = 250g
טבעות בצל        → ארגז = 10,000g, מנה = 250g
פחיות (כל סוג)   → ארגז = 24 יח׳, יחידה
בקבוקי שתייה     → ארגז = 24 יח׳ (אם נכון - אחרת תגיד), יחידה
בירות            → ארגז = 24 יח׳, יחידה
```
כל הפריסטים ניתנים לעריכה מהדף עצמו אחרי הבנייה.

### 3. מתכון - מה כל הזמנה מורידה
```text

smash-moshavnikim / crazy-smash / smash-double-cheese → קציצה 220g x1, לחמניה x1

haf-mifsha (צמחוני)                             → לחמניה x1 (בלי קציצה)
extra-patty / extra-smash-patty (תוספת)         → קציצה 220g x1
gluten-free-bun                                 → לחמניה ללא גלוטן x1 (במקום רגילה)

שתייה לפי סוג (can-cola, can-zero, beer-corona...) → היחידה המתאימה x1
```

### 4. מתי המלאי יורד / חוזר
- **יורד**: כשהזמנה עוברת ל-`ready` (המטבח סימן "מוכן").
- **חוזר**: כשהזמנה עוברת ל-`cancelled` (גם אם כבר ירדה).
- מימוש: **trigger ב-DB** על שינוי `orders.status` - אטומי, לא תלוי בקליינט.
- כל תנועה נרשמת ב-`inventory_movements` עם order_id ותאריך.

### 5. כשפריט מגיע ל-0
- מודאל בדף: "פחית קולה הגיעה ל-0 - לכבות באתר?"
- אישור → `menu_availability.available = false` לפריט המקושר.
- ביטול → נשאר זמין, אבל הפריט מסומן באדום ברשימה.

### 7. פריטי מלאי שיוזנו אוטומטית (seed - כולם מתחילים מ-0)
- בשר: קציצה 220g
- לחם: לחמניה רגילה, לחמניה ללא גלוטן
- צ׳יפס: צ׳יפס רגיל, צ׳יפס בטטה, טבעות בצל
- פחיות: קולה, זירו, פאנטה, ספרייט, בלו רגיל, בלו מוחיטו, בלו אבטיח, בלו דיי
- בקבוקים: ענבים, תפוזים, מים, מים בטעם תפוח, מים בטעם ענבים, סודה
- בירות: קלסטברג, גולדסטאר, הייניקן, קורונה, הוגרדן, לאף, אנפילטר, פאולנר

### פרטים טכניים

**טבלאות חדשות**:
- `inventory_items` - פריטי מלאי
- `inventory_recipes` - מה כל מנה צורכת
- `inventory_movements` - לוג תנועות
- `inventory_access_tokens` - ה-token הסודי

**Trigger**: על `orders.status` - יורד ב-ready, חוזר ב-cancelled.

**אבטחה**: כל הפעולות עוברות דרך edge function `inventory-action` שמאמת את ה-token. ה-DB עצמו לא חשוף לקליינט. אנונימוס לא יכול לקרוא/לכתוב ישירות.

**Realtime**: על `inventory_items` בלבד (דרך אותה edge function שמחזירה גם read-key אנונימי מוגבל).

**קבצים חדשים**: `src/pages/Inventory.tsx`, רכיבי `inventory/`, `supabase/functions/inventory-action/index.ts`, מסלול ב-`App.tsx`.
