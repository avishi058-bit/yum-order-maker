- Veg invoices are NOT one-time expenses; saved to produce tracking. Each purchase assumed to last until next purchase of same item.
- Cost per serving = cycle cost / burgers+crispy sold (deals count each burger).
- White onion = onion jam / fried onion. Ask "did previous onion jam run out?" before starting a new cycle.
- Unknown product names: never guess, ask the owner, then remember the name (e.g. "קריספי פלוס" = classic fries).
- Measured veg cost replaces 1.50 ₪ estimate in net profit ONLY after owner approves.
- Show price changes (up/down) vs previous purchase.
